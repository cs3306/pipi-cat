# 皮肤制作器 与 两种「API」

## 皮肤制作器
- 随本体一起安装，是独立窗口（`maker.html`），入口：设置 → 皮肤 → 「打开皮肤制作器」。
- 功能：基本信息（id/名称/作者/许可证/版本/简介）、颜色皮肤（取色器 + 花纹 + 高级里的原始 JSON）、图片皮肤（idle/blink/happy/shy 四个槽位）、实时预览（复用猫的绘制引擎）、导出 `.petskin`、直接安装到本软件（先出确认卡，再安装）。
- 预检逻辑在 `src/makerPack.ts`（有 node 测试）；真正的校验始终在安装时由后端 `pet-core` 再做一次。
- 第三种类型「分层皮肤」：每个部位一张图（躯干、头必填；四肢、尾巴可选），自动初始摆放 + 滑块微调支点/终点/挂点/层级，可选分段（肢体 2 段、尾巴 2–3 段）和闭眼/张嘴版头部图。规格见 `docs/skins/RIG-SPEC.md`。

## 两个互相独立的接口
| | MCP 接口（本体，可选） | 制作器 AI（制作器内） |
|---|---|---|
| 作用 | 让外部 AI 助手改皮肤和设置 | 把你写的描述发给你填的接口，换回一份调色板 |
| 方向 | 外部程序 → 本机端口 | 本软件 → 你填的地址 |
| 默认 | **关闭**（设置里「高级」开启，开启后监听 127.0.0.1 一个端口） | 未配置，不会联网 |
| 何时联网 | 不联网，只监听本机 | 仅在你点击「生成」时 |
| 密钥 | 无 | 默认只存内存；勾选「记住」才明文存本机 `maker-ai.json` |
| 校验 | `upsert_cat` 与皮肤包共用颜色校验；`skin-` 前缀 id 保留给皮肤包 | 回复当不可信输入：取 JSON → 同一套颜色校验 → 能转成猫皮肤配置才返回 |

AI 接口要求 OpenAI 兼容的 `/chat/completions`；地址必须 https，仅本机回环地址（localhost/127.0.0.1/::1）允许 http。发出的内容只有固定的字段说明和用户输入的描述（≤500 字）。

## 新增依赖
`ureq` 3（HTTP 客户端，默认 rustls）。需要在发布前用 cargo-about 生成第三方许可清单（见 RELEASE-CHECKLIST）。

## 打开已有皮肤、修改默认皮肤（beta 1）
- 制作器顶部「打开已有」：**从内置猫开始**（颜色配置载入，另存为新皮肤，原件不动）、**打开已安装的皮肤**（再次安装会替换它并保留上一版）、**从文件打开**（.petskin）。
- 设置 → 皮肤 →「默认皮肤」里的「修改外观…」以**覆盖模式**打开制作器：只能改颜色，按钮是「应用到这只猫」（立即生效，可在设置里撤销/恢复默认），没有导出与安装。内置外观本身不会被修改。
- 从文件打开的内容当作不可信输入：只取已知字段，导出/安装前仍走同一套校验。
