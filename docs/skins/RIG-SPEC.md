# 骨架与分层皮肤规范（草案 v1，对应 `kind: "layered"`）

状态：**1.0 beta 已实现（未经真机验证）**。格式 v1 定稿，以后只加可选字段，不改已有含义。
实现位置：后端校验 `pet-core/src/rig.rs` + `src-tauri/src/pet/skins.rs`；前端 `src/rig/*`（解析、姿态适配器、渲染器）；制作器 `src/makerRig.ts`；引擎钩子 `catEngine.setLayeredSkin`。

## 设计原则
1. **默认零选择**：用户只管安装、选用皮肤，没有任何骨架相关选项。皮肤自己携带全部信息。
2. **复杂度放进「高级」**：皮肤作者只需要提供最少的东西就能用；更精细的能力是可选字段（高级）。
3. **缺什么就降级，不报错**：缺的部位不画或用默认动作，永远不会把角色画坏。

## 骨架（拓扑固定，所有角色共用）
```
torso（根）
 ├─ head（颈部挂点）  ── 子通道：眼（闭合）、嘴（张开）、耳 L/R（抖动）
 ├─ limb: fl, fr      前肢（猫/狗=前爪，人物=手臂）
 ├─ limb: hl, hr      后肢（猫/狗=后腿，人物=腿）——可选，缺省收起
 └─ tail              第五肢——可选
```
最少只需要 `torso` + `head` 两张图。

## 坐标系
- 画布逻辑坐标，x 向右、y 向下，与引擎一致。原点 = 皮肤的「地面锚点」（底边中点）。
- 每个部位：`image`（data URI）、`pivot`（图内支点，0..1 归一化）、`attach`（支点放在锚点坐标系的位置，单位像素）、`z`（层级，整数）。
- 肢体与尾巴另有 `end`（0..1 归一化，图上「远端」的点）：支点指向 `end` 的方向就是**静止方向**，长度就是该段长度。`end` 离 `pivot` 至少 0.05。
- 分段（`segments`，最多 3 段）每段是 `{image, pivot, end}`：下一段的支点接在上一段的 `end`。图片按「静止姿势」画：肢体向下伸直，尾巴向右伸直。
- 全局 `scale`（默认 1）：皮肤作者按自己的图片尺寸整体缩放；用户可在「高级」里再微调缩放与上下偏移（每个皮肤各存一份，不进皮肤包）。

## 姿态（动画只输出这个，不涉及美术）
| 部位 | 字段 |
|---|---|
| torso | `dx, dy`（位移）、`lean`（前倾 -1..1）、`squash`（压缩 0.9..1.1） |
| head | `tilt`（弧度，±1.2）、`nod`（-1..1）、`gazeX/gazeY`（-1..1）、`eyesClosed`、`mouthOpen`、`earTwitchL/R`（0..1） |
| limb × 4 | `target`（要够到的点；`null` = 回到静止位置）、`planted`（是否按在桌面上） |
| tail | `angle`（根部角度）、`curl`（卷曲 -1..1）、`sway`（摆动相位） |
| props | 头 / 躯干 / 嘴 挂点上的道具 id |
所有数值都会被钳制到合法范围。

## 皮肤包字段（在通用字段之外）
```jsonc
"rig": {
  "scale": 1,
  "parts": {
    "torso": { "image": "data:...", "pivot": [0.5, 0.9], "attach": [0, 0], "z": 10 },  // 必填
    "head":  { "image": "data:...", "pivot": [0.5, 0.85], "attach": [0, -120], "z": 20,
               "eyesClosedImage": "data:...",     // 可选：眨眼用
               "mouthOpenImage": "data:..." },    // 可选
    "limbs": { "fl": { ... }, "fr": { ... } },    // 可选；hl / hr 更可选
    "tail":  { "image": "data:...", "pivot": [0.1, 0.5], "attach": [60, -40], "z": 5 }    // 可选
  }
}
```
### 渐进式：能力分级
| 级别 | 内容 | 谁适合 |
|---|---|---|
| L0 | 单张 idle 图（`kind: sprites`） | 最简单，已实现 |
| L1 | 四状态图 idle/blink/happy/shy（`kind: sprites`） | 已实现 |
| L2 | `layered`：torso + head（+ 可选前肢、尾巴，单片刚体） | 默认的分层皮肤 |
| L3（高级字段） | `tail.segments`（2–3 段链式弯曲）、`limbs.*.segments`（2 段 + 关节，两段 IK）、`hl/hr` 后肢、`eyesClosedImage`/`mouthOpenImage` | 追求细腻的作者 |

`eyesClosedImage` / `mouthOpenImage` 是**整张头部替换图**（与 `head.image` 同尺寸、同支点），闭眼（含眨眼、睡觉）/张嘴时替换主头图；同时满足时闭眼优先。

### 降级规则
- 无 `limbs` → 前肢不画（躯干图里自带手的话也没问题）；无 `hl/hr` → 收起。
- 无 `tail` → 不画；`tail` 单片 → 绕支点旋转（`curl` 近似为额外偏转）。
- 无 `eyesClosedImage` → 眨眼用头部纵向微压缩；无 `mouthOpenImage` → 忽略。
- 肢体单片 → 旋转 + 沿长度拉伸去够 `target`；有 `segments` → 两段骨骼 IK。

## 限制与校验（沿用图片皮肤的规则，仅调整总量）
单图 ≤ 1.5 MB、PNG 每边 ≤ 2048、只收 PNG/WebP（看文件头）、最多 16 张图、图片合计 ≤ 6 MB、整个文件 ≤ 12 MB；`attach` 绝对值 ≤ 2000、`pivot`/`end` 在 0..1、`z` 在 -100..100、`scale` 在 0.1..4、分段 ≤ 3；`rig.parts` 里只允许 torso/head/limbs(fl,fr,hl,hr)/tail，未知部位直接拒绝（不静默忽略）。可选字段缺省即降级。分层皮肤不能同时带 `palette` 或 `sprites`。

## 与引擎的衔接（已实现的映射，及没有的）
适配器 `poseFromInput`（`src/rig/rigPose.ts`，有测试）把引擎状态翻译成姿态：
| 引擎状态 | 姿态 |
|---|---|
| 呼吸 | 躯干上下微动 + 轻微压缩 |
| 打字强度 | 前倾、点头 |
| 睡眠 / 眯眼 / 开心 / 害羞 | 闭眼（含眨眼计时）、害羞时头偏一点 |
| 左右爪的位置（戳键/鼠标时） | 前肢 `fl`/`fr` 的目标；爪回到空闲时肢体回静止 |
| 甩尾巴（拍桌）状态 | 尾巴整体偏转 + 卷曲；平时缓慢摆动 |
| 头部倾斜弹簧 | 头部倾斜 |
**没有映射**：后肢 `hl/hr` 一直保持静止；耳朵抖动通道保留但 1.0 没有耳朵图层；张嘴（叫声时）未驱动；眼睛视线未驱动。程序化猫、「大肥鱼」、图片皮肤都不受影响。

## 皮肤页的「高级」（已实现）
每个图片/分层皮肤一个折叠区：大小（0.4–2）与上下位置（±120）两个滑块 + 重置。存在本机 localStorage（设置窗口与猫窗口同源，实时同步），不进皮肤包。

## 制作器（已实现）
制作器的「分层皮肤」类型：选图后自动给初始摆放与整体缩放，用滑块调支点/终点/挂点/层级，可选分段；右侧实时预览；导出或直接安装。
