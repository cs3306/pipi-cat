# 1.0 beta 发布清单

## 必须在发布前完成（代码里已留好位置）
1. **产品名**：当前仍沿用 KuroCat 名称。MIT 不授予商标，建议改名，避免与上游混淆。需要改的地方：
   `src-tauri/tauri.conf.json`（productName、identifier、publisher、shortDescription）、
   `src-tauri/Cargo.toml`（package name、`[[bin]] name`，注意 `KuroCat` 也出现在 `build.rs`、`input_hook.rs`、`lib.rs` 的错误文案里）、
   `menu.html`、`src/menuMain.ts`、托盘文案（`tray.rs`）、`src-tauri/windows/hooks.nsh`、README。
   `config::app_data_dir()` 里的目录名已改为 `pipi-cat`（与上游 `kuro-cat-pet` 分开，两个软件可同时安装互不干扰），，老用户的设置不会迁移（新产品可接受）。
2. **更新器**：`src-tauri/src/updater.rs` 顶部——把 `OWNER/REPO` 换成你的发布仓库，再把 `UPDATES_CONFIGURED` 改成 `true`。
   在此之前整个更新检查是关闭的（不会再提示用户换回上游版）。
3. **版权行**：`LICENSE` 追加你的版权行；`NOTICE.md` 里的占位符改成你的名字。
4. **第一次 Actions 构建**：`pet-core` 已用 cargo 测试通过，但 `src/pet/` 下依赖 tauri / notify / windows-sys 的代码从未编译过，预期要按日志修几轮。改命令时要同步 `src/pet/mod.rs` 的 COMMANDS 和 `build.rs` 的 PET_COMMANDS（有测试检查）。
5. **真机验证**（至少 Win10/Win11 各一台）：见下方「手测清单」。

## 手测清单
- 首次启动：设置窗口自动弹出并停在「隐私」页，欢迎卡片选择「开启 / 暂不开启」后卡片消失。
- 专注：右键菜单「开始专注」→ 右上角出现倒计时；把专注时长设为 1 分钟，走完后 +金币，气泡提示；中途停止不加金币。
- 无操作 30 秒（可调）后出现围裙与擦杯子/端盘子动作；一动鼠标键盘立即消失。
- 零食：金币够时买猫条/罐头出现道具与小心心；不够时提示差多少且不扣币。
- 提醒：设置里开「喝水」，把间隔改为 1 分钟，应出现气泡；猫被隐藏时先显示再提醒。
- 定时关机：设 1 分钟 → 约 60 秒前猫提示 → 设置里取消 → 确认没有关机（`shutdown /a` 成功）。勾选「强制」时有二次确认。
- 文件反应（开启后，隐私页勾选桌面/下载）：往桌面放一个文件 →「有新东西～」；删除一个文件 →「删掉啦！」；专注期间默认静音；`.tmp`/下载中的文件不触发。
- 猫叫（开启后）：把间隔设为 1 分钟、无操作；全屏播放视频时不叫；放入自己的音频后随机播放它。
- 杀软：用 Windows Defender 扫描安装包；记录是否被 SmartScreen 拦截。

## 皮肤手测
- 设置 → 皮肤：用 `node tools/pack-skin.mjs docs/skins/examples/sunny-palette` 打包后安装；确认弹出的确认卡片显示作者/许可证，安装后右键菜单里能选到，选中后毛色变化。
- 拖入 `.petskin` 到设置窗口能触发（依赖 `disable_drag_drop_handler`）；点「从文件安装」也能用。
- 图片皮肤：做一个 idle.png（透明背景）打包安装，选中后猫被图片替换，键盘仍在图片前面；位置/大小是否合适需要肉眼调（常量在 `catEngine.ts` 的 `drawSpriteScene`）。
- 坏包：改成 `kind: "script"`、删掉 license、把图片换成 SVG，都应被拒绝并显示提示。

## 已知局限（写进 release notes）
- 文件反应：只监听勾选的文件夹本身（不含子文件夹）；重命名不触发；删除和移走都算「消失」。
- 叫声默认是电子合成音；想要真实猫叫请把自己的录音放进自定义文件夹（需自己有权使用）。
- 猫薄荷、重量版猫咖、多角色/狗/人物暂未包含；图片皮肤只有静态四态（idle/blink/happy/shy），没有手、尾巴等部位动画；分层皮肤（`kind: layered`）留给后续版本。
- 仅发布 Windows 10/11 版；上游的 macOS/Linux/Win7 构建未经本版本验证。
- 安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
